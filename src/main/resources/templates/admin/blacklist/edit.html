Ban Formatting Documentation

The security firewall engine dynamically parses entries based on syntax configuration formatting rules:

  • Single IP Address: Enter literal numeric targets (e.g., 198.12.69.94). Used by filters to instantly drop requests from that machine.
  • Network Subnet Range: Append CIDR notations (e.g., 198.46.154.0/23). Blocks large chunks of rotating adjacent server addresses owned by budget hosts.
  • Email Domains: Input clean root strings (e.g., formtests.info). Utilized by DomainValidator during user account signups to block spam boxes.

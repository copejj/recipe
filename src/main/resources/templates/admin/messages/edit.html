How Dashboard Banners Work

  • Priority: The dashboard displays the single most recently created message that has not yet expired.
  • Global vs. Targeted: Leave Audience set to Global Broadcast to notify everyone, or pick a specific chef for an account notice.
  • Quick Shutoff: Use Expire Now on the list page to immediately take down a banner without deleting its history.
